# Hi, I'm neotu 👋

I like building **small tools I genuinely want to use, but can never quite find in the form I want**.

Most of my projects start with the same question:

> “Why isn't there a simpler tool for this?”

If that thought keeps coming back, I usually try to build one.

I care more about **thinking through the problem** than adding more features. As AI makes implementation cheaper, judgment becomes more valuable: **what is worth building, and what should be left out.**

### Kanvi

**Turn reference designs into reusable publishing templates.**

`Private` · `AI` · `Work in progress`

### PodNotes

**Turn audio and video into knowledge you can actually keep.**

`Private` · `Local AI` · `Automation` · `Work in progress`

## A few things I believe

**Good software should hide complexity, not expose it.**

**AI makes building cheaper. Choosing what to build becomes more important.**

**Small tools can solve real problems.** Not everything needs to become a platform.

**Build first, then judge.** A lot of ideas only become clear once they exist.
