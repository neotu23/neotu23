# 你好，我是 neotu 👋

我喜欢做那些**自己真正想用，但市面上总觉得差一点意思的小工具**。

很多项目都从同一个问题开始：

> “为什么这件事没有一个更简单的工具？”

如果这个念头反复出现，我通常就会自己做一个。

我更在意**把问题想清楚**，而不是把功能堆得更多。AI 让实现变得越来越便宜，真正稀缺的反而是判断：**什么值得做，什么应该删掉。**

## 正在开发

### WriterOK

**一个尽量不打断写作的 AI 写作工具。**

需要时帮你续写、润色、重写；不需要时，就安静地做一个写作工具。

`Private` · `AI-native` · `Work in progress`

### Unsunk

**一个原生 macOS 的订阅与持续支出管理工具。**

用菜单栏更轻量地管理订阅、充值型项目和持续支出，关注“钱正在以什么速度流出去”。

`Private` · `Swift` · `macOS` · `Work in progress`

### Kanvi

**把参考设计变成可复用排版模板。**

从参考内容中提取设计风格，将 Markdown 套入模板，并进行预览、规则验证与输出。

`Private` · `AI` · `Work in progress`

### PodNotes

**把音视频变成可以真正进入知识库的文字。**

从播客、YouTube 或本地音视频开始，本地转录、按需翻译，再整理进 Obsidian。

`Private` · `Local AI` · `Automation` · `Work in progress`

## 我相信的几件事

**好软件应该隐藏复杂性，而不是把复杂性暴露给用户。**

**AI 让“做出来”越来越便宜，选择“做什么”会越来越重要。**

**小工具也可以解决真正的问题。** 不一定需要成为一个庞大的平台。

**先做，再判断。** 很多想法只有真正做出来，才知道它值不值得继续。
