# 你好，我是 neotu 👋

我喜欢做那些**自己真正想用，但市面上总觉得差一点意思的小工具**。

很多项目都从同一个问题开始：

> “为什么这件事没有一个更简单的工具？”

如果这个念头反复出现，我通常就会自己做一个。

我更在意**把问题想清楚**，而不是把功能堆得更多。AI 让实现变得越来越便宜，真正稀缺的反而是判断：**什么值得做，什么应该删掉。**

## 我相信的几件事

**好软件应该隐藏复杂性，而不是把复杂性暴露给用户。**

**AI 让“做出来”越来越便宜，选择“做什么”会越来越重要。**

**小工具也可以解决真正的问题。** 不一定需要成为一个庞大的平台。

**先做，再判断。** 很多想法只有真正做出来，才知道它值不值得继续。
